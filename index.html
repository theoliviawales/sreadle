Export / import

Export copies this rhythm as JSON: name, tempo and every measure, in the same element format the creator and the game's authored days use. To publish a rhythm for every player, paste the exported JSON into the site's authored rhythms (see the deployment plan in the game view).

How to play

1. Tap the pad (or press any key) exactly when each note crosses the amber line.

2. The metronome counts you in for one measure, then clicks every beat for the whole round. A note with a tiny grace note before it is a flam: two quick taps, grace first, then the beat.

3. You get 2 attempts at each day's rhythm. A new puzzle arrives at midnight, Seattle time.
